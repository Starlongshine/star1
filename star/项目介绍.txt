        基于 NSGA-II 的算力互联网资源调度策略 —— 项目代码介绍文档
================================================================================

一、项目概述
────────────────────────────────────────────────────────────────────────────────
本项目是论文《基于NSGA-II的算力互联网资源调度策略研究》的完整仿真代码实现。

核心思路是：在算力互联网环境下，用户提交各种类型的计算任务（AI训练、视频渲染、
科学计算等），系统需要决定把每个任务分配给哪个算力平台（核心节点/区域节点/边缘
节点）去执行，同时尽量让时延最短、成本最低。

这是一个典型的多目标优化问题（两个目标互相冲突），本项目采用：
  第一阶段：改进的 NSGA-II 算法 —— 搜索出一批"两个目标都不差"的候选方案（Pareto解集）
  第二阶段：DW-TOPSIS 决策模型 —— 从候选方案中综合评分，选出最终最优调度方案


二、文件结构说明
────────────────────────────────────────────────────────────────────────────────
E:\star\
│
├── models.py           【数据模型】
│     定义了平台（Platform）和任务（Task）两个核心数据结构，以及
│     节点类型（核心/区域/边缘）、任务类型（AI训练/AR渲染/推理等）、
│     区域（华北/华南/华东/华西/华中）和区域间距离矩阵。
│
├── problem.py          【问题定义】
│     把调度问题转化为数学模型：
│     - 预计算每对"任务-平台"的时延矩阵和成本矩阵
│     - 实现目标函数计算（平均时延 f1、总成本 f2）
│     - 实现约束检测（平台容量约束、SLA截止时间约束）
│     - 提供SLA满足率等统计接口
│
├── nsga2_improved.py   【核心算法：改进的 NSGA-II】
│     本论文的主要创新点，在标准NSGA-II基础上做了三处改进：
│
│     改进1：混沌种群初始化
│       用 Logistic 混沌映射（x_n+1 = 4*x_n*(1-x_n））生成初始种群，
│       相比随机初始化分布更均匀，避免初期搜索区域过于集中。
│
│     改进2：混沌自适应变异率
│       每一代的变异概率不再固定，而是由混沌序列动态调节，
│       前期保持多样性探索，后期加强局部搜索，帮助跳出局部最优。
│
│     改进3：方向引导的拥挤距离
│       标准NSGA-II用拥挤距离衡量解的分散程度，本文在此基础上
│       引入偏好向量，用余弦相似度衡量每个解与偏好方向的吻合程度，
│       使算法能向用户指定的偏好区域（如"更侧重时延"）倾斜。
│       改进公式：CD_改进 = α × 余弦相似度 + (1-α) × 标准拥挤距离
│
├── dw_topsis.py        【决策模型：双权 TOPSIS（DW-TOPSIS）】
│     对 NSGA-II 输出的 Pareto 解集进行综合排序，选出最终方案。
│     核心创新：将主观权重与客观权重融合
│
│     主观权重：根据任务类型（AR渲染任务时延优先、AI训练任务成本优先等）
│               由专家经验预先设定，反映业务策略导向。
│
│     客观权重：用熵权法计算，根据各指标在Pareto解集中的数据分布来确定，
│               分布越分散的指标信息量越大，权重越高。
│
│     综合权重 = 主观权重 × 客观权重（归一化）
│
│     最后按 TOPSIS 流程计算每个解与理想解/负理想解的距离，
│     输出相对贴近度排名，选出最优方案。
│
├── baselines.py        【对比算法】
│     实现了5个对比基线算法，用于在实验中与本文算法作性能比较：
│
│     MinMin          - 经典启发式：每次选当前完成时间最短的任务-平台对
│     PSO             - 粒子群优化（单目标，最小化时延）
│     GeneticAlgo     - 标准遗传算法（单目标）
│     StandardNSGAII  - 原始NSGA-II（无任何改进，用于消融实验）
│     MOPSO           - 多目标粒子群优化（带Pareto外部档案）
│
├── data_generator.py   【数据生成】
│     生成仿真实验所需的平台集合和任务集合：
│
│     平台参数（随机生成，符合实际范围）：
│       核心节点：计算能力 100-200 TFLOPS，带宽 20-40 Gbps，成本较高
│       区域节点：计算能力  30-80  TFLOPS，带宽  8-20 Gbps，成本中等
│       边缘节点：计算能力   5-20  TFLOPS，带宽  2-10 Gbps，成本较低
│
│     任务参数（按类型不同设定不同范围）：
│       AI训练/科学计算：计算量大（50-800 TFLOP），截止时间宽松
│       AR渲染/视频流：  计算量小，截止时间严格（0.5-8秒）
│       轻量推理/数据分析：计算量小，截止时间适中
│
├── experiment.py       【实验驱动器】
│     组织并运行三类实验：
│       单场景实验  - 完整对比6种算法，输出所有指标和图表
│       可扩展性实验 - 任务数从20增至200，测试各算法的规模适应性
│       敏感性实验  - 三种任务组合（时延敏感型/成本敏感型/混合型），
│                     验证偏好引导机制对不同任务场景的适配效果

├── visualization.py    【可视化】
│     生成6类图表（均保存为PNG）：

│       平台负载分布图    - 展示各平台的资源利用率（绿/橙/红色区分健康程度）
│       任务-节点匹配热力图 - 分析各类任务被分配到哪类节点（验证优先匹配效果）
│       可扩展性折线图    - 展示不同任务规模下各算法的性能变化趋势

三、运行方法
────────────────────────────────────────────────────────────────────────────────
【第一步】安装依赖（只需一次）
  在命令行（cmd 或 PowerShell）进入 E:\star 目录后执行：
    pip install numpy matplotlib

【第二步】运行实验
  cd E:\star

  # 运行全部实验（主实验 + 可扩展性 + 敏感性）
    python main.py --mode all

  # 只运行主实验（50个任务，200代，约4分钟）
    python main.py --mode single

  # 只运行可扩展性实验
    python main.py --mode scalability

  # 只运行敏感性实验
    python main.py --mode sensitivity

  # 自定义参数示例（100个任务，300代，侧重时延）
    python main.py --n_tasks 100 --n_gen 300 --pref_delay 0.8

【常用参数说明】
  --n_tasks     任务数量（默认50）
  --pop_size    种群规模（默认100，越大结果越好但越慢）
  --n_gen       迭代代数（默认200，越多结果越好但越慢）
  --pref_delay  时延偏好权重，0~1（默认0.5，设0.8表示更侧重时延优化）
  --seed        随机种子（默认42，固定后结果可复现）
  --mode        实验模式：single / scalability / sensitivity / all

敏感性实验结果（验证偏好引导效果）：
  - 设置"时延敏感"偏好（pref_delay=0.8）→ 时延降至 3.36s（比Min-Min低33%）
  - 设置"成本敏感"偏好（pref_delay=0.2）→ 成本降至 232.5yuan（比Min-Min低52%）
  这说明 DW-TOPSIS 的主观权重机制可以有效引导调度偏好。

可扩展性实验：
  - 20任务 → 200任务，SLA满足率始终保持在97%以上
  - 改进NSGA-II在时延指标上随规模增长的劣化幅度优于Min-Min和PSO


五、算法流程简述（用于论文写作参考）
────────────────────────────────────────────────────────────────────────────────

  输入：任务集合 T = {t1,...,tN}，平台集合 P = {p1,...,pM}

  Step 1  建模
    - 计算时延矩阵 D[i][j] = 计算时延 + 传输时延（传播+带宽）
    - 计算成本矩阵 C[i][j] = 计算成本 + 跨域传输成本

  Step 2  改进NSGA-II 搜索（生成Pareto候选解集）
    ① 混沌初始化种群（Logistic映射，均匀覆盖解空间）
    ② 评估每个解的两个目标：f1=平均时延，f2=总成本（含约束惩罚）
    ③ 快速非支配排序 → 分层前沿
    ④ 方向引导拥挤距离计算（余弦相似度 + 标准拥挤距离）
    ⑤ 锦标赛选择 → 单点交叉 → 混沌自适应变异
    ⑥ 父代+子代合并 → 环境选择保留最优pop_size个解
    ⑦ 重复②-⑥共 n_gen 代
    ⑧ 输出 Pareto 最优解集

  Step 3  DW-TOPSIS 决策（从Pareto集选最终方案）
    ① 提取解集的目标矩阵（时延列、成本列）
    ② 计算主观权重（按任务类型分布加权）
    ③ 熵权法计算客观权重
    ④ 综合权重 = 主观×客观（归一化）
    ⑤ 构建加权标准化矩阵
    ⑥ 计算各解与理想解/负理想解的距离
    ⑦ 排序输出最优调度方案

  输出：最终任务-平台分配方案 x[i] = j（任务i分配给平台j）
